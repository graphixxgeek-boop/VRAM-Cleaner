# VRAM Cleaner v1.3 — by CycleBlue

Surveillance et libération de la VRAM NVIDIA.

## Lancer

Double-cliquez sur **Lancer VRAM Cleaner.bat**

## Icône

1. Convertissez votre logo en **`.ico`** (ex. https://icoconvert.com)
2. Nommez-le **`vram_cleaner.ico`**
3. Placez-le **dans le même dossier** que `vram_cleaner.pyw`
4. Relancez l’application

Pour l’exe : lancez `RECREER_EXE_ONEDIR.bat` avec le `.ico` déjà présent.
